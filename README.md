**AI Image Generator (n8n + OpenAI)**
This is an AI Image Generator workflow built using n8n and OpenAI.

**Features**
Takes a text prompt from a chat window.
Generates a high-quality image using OpenAI's image model.
Returns the generated image.

**Tech Stack**
n8n (Workflow Automation)
OpenAI API (Image Generation)

**How to use**
Import the JSON file into your n8n workspace.
Add your OpenAI API credentials.
Open the chat and type a prompt (e.g., "A cute cat wearing a magician's hat").
The workflow will generate the image.
